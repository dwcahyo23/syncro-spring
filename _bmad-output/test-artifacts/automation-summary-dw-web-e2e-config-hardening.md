### Fix discovered during the run (WH-01): the naive `test:api` script was broken

The test-design's T-WH-P1-01 suggested `playwright test tests/api`. Verification proved that approach fails: Playwright resolves positional args against `testDir` (`./tests/e2e`), so `tests/api` matches nothing and `--list` reports "No tests found" (exit 1). The working fix is the dedicated `playwright.api.config.ts` (testDir `./tests/api`, no webServer since API tests use the `request` fixture). This is the highest-value verification action for the bundle, closing DW-10.
