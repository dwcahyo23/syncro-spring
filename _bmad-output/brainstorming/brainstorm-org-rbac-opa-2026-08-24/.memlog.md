- (technique) started Role & Policy Matrix (key deliverable)
- (idea) POLICY SUPER_ADMIN: full CRUD semua resource, semua scope, semua action, no restrictions
- (idea) POLICY PLANT_MANAGER: read global dashboards OEEMTBF telemetry, approve budget/workorder > threshold, export reports
- (idea) POLICY DEPT_HEAD: full CRUD scope sendiri, read dashboards lintas dept dalam plant, assign section assignments

- (idea) POLICY TECHNICIAN: execute assigned workorders, log work, request sparepart, view machine history, update task status

- (idea) POLICY PLANNER: create/assign preventive schedule, view resource availability, view maintenance calendar

- (idea) ARCH input policy: subject (user,roles,dept,section,teams) + resource (machine/part/WO) + action + context
- (idea) ARCH resource scope diturunkan dari machine->section->dept->plant di PostgreSQL sebagai data kebenaran
- (idea) ARCH frontend panggil endpoint /allowed-actions (bukan enforce) untuk render UI; enforce tetap server-side
- (idea) ARCH bundle Rego dideploy via CI (test fixtures) bukan diedit langsung di produksi
- (idea) POLICY ABAC: mesin kritis (critical flag) hanya ENGINEER+ boleh edit config, operator read saja

- (idea) POLICY role temporary: assignment role/team punya expiry date, auto-revoke
- (idea) POLICY segregation pabrik: user plant A tidak boleh lihat data plant B kecuali role group
- (idea) POLICY preventive: planner create schedule hanya di section sendiri; teknisi lihat schedule yg ditugaskan

- (idea) POLICY OEE dashboards: production lihat OEE/counter/stop; maintenance lihat detail log; keduanya read-only pada punya orang lain
