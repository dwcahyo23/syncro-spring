- (insight) CMMS canonical WO status: Open/CRTD -> In Progress/INPR -> On Hold (optional) -> Done/TECO -> Business Close/CLSD; SAP menambah tahap technically complete sebelum business close
- (insight) MTBF = total uptime / jumlah failure (hanya corrective); MTTR = total waktu repair / jumlah repair (exclude logistic delay); Availability = MTBF/(MTBF+MTTR); research mendukung formula yang sudah kita desain
- (insight) PM scheduling: calendar-based fixed/floating, meter-based fixed/floating, runtime-based (combined); due date anchor + scheduling horizon (pre-generate N hari ke depan) - selaras preventive by shift/kalender tanpa telemetry
- (insight) Part request workflow CMMS: Assigned -> Committed/Reserved -> Issued -> Consumed; reorder point = minimum trigger, order qty = max-current; selaras OP/OQ kita
- (insight) Technician rating bintang BUKAN standar CMMS; industri pakai KPI objektif: on-time %, WO completed/period, MTTR, rework %, schedule compliance. Rating kita adalah nilai tambah, harus didampingi KPI objektif
- (insight) Report 4-sentence convention (Chronological/Analysis/Corrective/Preventive) = pola repCh/repAn/repCr/repPr yang sudah ada di referensi - retain
- (insight) FMEA maintenance: failure codes Problem->Cause->Action, RPN=SxOxD; corrective actions dari FMEA jadi task instruction di PM workorder
- (insight) OPA sidecar HTTP = rekomendasi resmi utk non-Go; java-opa-sdk (embedded IR) early-stage; WASM ada limit built-ins; bundle signed+versioned + status API + decision log (mask/drop PII) + opa test di CI
- (insight) OPA anti-pattern: jangan simpan org data di OPA data store (pass via input, JWT->input->bundle->push->pull); minimal self-contained input; jangan cache allow; default-deny; decision_id di audit trail app
- (insight) allowed_actions query (set/array) lebih simple dari partial evaluation utk menu frontend; PE untuk row-level filtering SQL; frontend hiding = UX only, enforce tetap server-side
