# BMad Phase 4 Workflow Map Notes

Source: https://docs.bmad-method.org/reference/workflow-map/

- Phase 4 goal: build one story at a time.
- `bmad-sprint-planning`: initialize tracking once per project; creates `sprint-status.yaml`.
- `bmad-create-story`: prepare next story; creates `story-[slug].md`.
- `bmad-dev-story`: implement story; creates working code and tests.
- `bmad-code-review`: review implementation; returns approval or change requests.
- `bmad-correct-course`: handle major mid-sprint changes; creates updated plan or reroute.
- `bmad-sprint-status`: track sprint progress and story status; creates sprint update.
- `bmad-retrospective`: review after epic completion; creates lessons learned.
- `bmad-investigate`: forensic investigation; creates `{slug}-investigation.md`.

Project shortcuts:

- `/status` wraps status inspection and next-action recommendation.
- `/dev` wraps one-story implementation loop.
- `/pivot` wraps correction routing.
